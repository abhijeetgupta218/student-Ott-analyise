🧠 Project Title:

Analysis of OTT Platform Usage Among Students

🎯 Objective / Aim:

The goal of this project is to analyze how students spend their time on various OTT platforms such as Netflix, Prime Video, and YouTube, and to understand how factors like devices used, preferred genres, and subscription type affect viewing habits and engagement levels.
The project aims to uncover insights into streaming behavior trends among students across different age groups and genders.

📂 Dataset Description:

File Name: Student_OTT_Usage.xlsx
Number of Records: 800

Key Columns:

Student_ID: Unique ID for each student

Name: Name of the student

Age: Student’s age (18–25 years)

Gender: Male / Female

Netflix: Whether the student uses Netflix (Yes/No)

Prime: Whether the student uses Amazon Prime Video (Yes/No)

YouTube: Whether the student uses YouTube (Yes/No)

Device_Used: Device used to watch OTT (Mobile, Laptop, Smart TV, Tablet)

Hours_per_day: Average time spent daily on OTT platforms

Favourite_Genre: Most preferred content genre (Comedy, Drama, Thriller, etc.)

Subscription_Type: Type of access (Free or Paid)

🧩 Technologies and Libraries Used:

Python 3

Pandas – For data creation, cleaning, and analysis

Matplotlib & Seaborn – For graphical visualization

ReportLab – For exporting data reports to PDF

OpenPyXL – For saving datasets in Excel format

📑 Output Files:

Student_OTT_Analysis_Project.py → Main analysis and visualization script

Student_OTT_Usage.xlsx → Dataset file

Student_OTT_Usage_Report.pdf → Generated PDF report containing analysis and graphs

README.txt → Project summary and documentation

🧾 Conclusions / Key Insights:

YouTube has the highest number of users among students.

Students using Smart TVs and Laptops spend more average time watching OTT.

Comedy and Drama are the most preferred genres across genders.

Students with Paid subscriptions spend significantly more time streaming.

OTT usage peaks during weekends, suggesting strong entertainment-based engagement.
